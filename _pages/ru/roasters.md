Можно встроить данные прямо в страницу кофе или отдавать их отдельным JSON-файлом либо через API. В обоих случаях QR-код с пачки может вести на существующую страницу кофе, лота или пачки.

## 1. Встроить данные в страницу

1. [Откройте конструктор профиля кофе]({{ '/ru/roasters/profile-builder/' | relative_url }}), заполните сведения о кофе и добавьте рецепты заваривания.
2. Нажмите **Сформировать HTML**, затем **Скопировать HTML**.
3. Вставьте готовый блок в HTML страницы, на которую ведёт QR-код с пачки. Если за сайт отвечает разработчик, передайте блок ему.

Конструктор помещает данные в тег `<script>` с типом `application/json`. Ниже показано, как подготовить такой блок вручную.

## 2. Подключить отдельный API или JSON-файл

Отдавайте полный профиль кофе одним ответом с `Content-Type: application/json`. Укажите адрес профиля одним из двух способов.

### Тег `<link>` в HTML

Добавьте тег в `<head>` страницы, на которую ведёт QR-код.

~~~html
<link rel="https://beanzen.ru/rel/brew-profile"
      href="https://your-roastery.example/profiles/coffee.json"
      type="application/json">
~~~

### Заголовок `Link` в HTTP-ответе

Добавьте заголовок в ответ страницы или в один из редиректов по QR-коду.

~~~http
Link: <https://your-roastery.example/profiles/coffee.json>; rel="https://beanzen.ru/rel/brew-profile"; type="application/json"
~~~

В адресе профиля укажите все параметры запроса, которые нужны вашему API. Страница и профиль должны быть доступны по HTTPS. Beanzen сначала ищет заголовок `Link`, затем тег `<link>`, а после него — встроенные данные в `<script>`.

## Проверьте пример

[Откройте пример встроенного профиля]({{ '/ru/roasters/examples/inline-profile/' | relative_url }}). Он содержит один тестовый кофе, одну пачку и два полных рецепта.

Откройте пример на компьютере и отсканируйте его QR в Beanzen. Приложение должно показать **Beanzen Demo Coffee**, пачку **250 г** и дату обжарки **2026-11-01**. В профиле есть **Demo V60** и **Demo French press**. Получение рецептов, их хранение и ведение заваривания - отдельные возможности приложения.

## Как подготовить встроенный блок вручную

Конструктор использует `brew-profile 0.5`, формат JSON для сведений о кофе и рецептах. Если готовите профиль вручную, вставьте его в один блок в исходном HTML страницы кофе.

~~~html
<script id="beanzen-brew-profile" type="application/json">
{
  "schemaVersion": "0.5",
  "coffee": [{
    "id": "019a55b0-0000-7000-8000-000000000001",
    "roaster": "Example Roaster",
    "name": "Example lot",
    "beans": [{"country": "KE", "processing": "washed"}]
  }]
}
</script>
~~~

Включите один кофе и все связанные с ним рецепты. Данные пачки передавайте, только если они относятся к конкретной пачке. Типовая фасовка товара не определяет экземпляр пачки. Кофе и рецептам назначьте устойчивые UUIDv7.

Сериализуйте JSON и замените каждый `<` на `\u003c` перед вставкой. Не включайте сведения о покупателях, секретные ключи и необработанные данные маркировки Data Matrix. Профиль должен находиться в исходном HTML, без iframe и загрузки через JavaScript.
